# Stonetop for Foundry VTT

> [!IMPORTANT]
> **This repository is no longer maintained.** Development has been picked up by [@taylor-nightingale](https://github.com/taylor-nightingale) in their fork: **https://github.com/taylor-nightingale/stonetop**. Please use that fork for installation, issues, and updates.

This is a system for Foundry VTT that is designed to support the Stonetop RPG. The game itself is currently in development, consider this an unstable module.

## Installation

You need the Powered by the Apocalypse system installed to use this module. You can find it [here](https://foundryvtt.com/packages/pbta).

To install the module, use the manifest URL from the actively-maintained fork: `https://raw.githubusercontent.com/taylor-nightingale/stonetop/main/module.json`
